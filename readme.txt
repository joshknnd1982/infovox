The User's Guide for the Infovox 230 and the Infovox 330, 
and the Language Manual for all the languages available 
with Infovox 230 and Infovox 330, are stored in this CD
in two formats: 

- RTF format

- Microsoft Word 6.0


RTF files have the advantage that they are readable by 
basicly any word processor (including WordPad). The only 
drawback is that different depending Word Processor might 
show the document in different ways, depending on its 
formatting capabilities. WordPad for instance might loose 
some of the spacing and table information.

You'll find the document in the RTF format in the RTF 
subdirectory.

Microsoft Word 6.0 format on the other hand guarantees 
that the file appears as it was thought, but it requires 
the user to have installed Microsoft Word 6.0 or later, 
or the freeware "Word 97 Viewer" available at Microsoft 
Web-Site. Please note that you can also open RTF files 
from Microsoft Word.

You'll find the document in Microsoft Word 6.0 format in 
the WORD subdirectory.
